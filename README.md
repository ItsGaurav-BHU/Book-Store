 📚 BookStore - MERN Stack Project

A full stack **BookStore web application** built using the **MERN Stack (MongoDB, Express.js, React.js, Node.js)**.
This project allows users to browse books, explore free courses, and experience a modern responsive UI with authentication and dark/light mode support.

🚀 Features

* 📖 Browse available books
* 🎓 Free courses section
* 🔐 User authentication (Signup & Login)
* 🌙 Dark / Light mode toggle
* 📱 Fully responsive UI
* ⚡ Fast frontend using **Vite + React**
* 🗄 Backend REST API with **Express & MongoDB**



🛠 Tech Stack

 Frontend

* React.js
* Tailwind CSS
* DaisyUI
* React Router
* Vite

Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

 Run Backend

cd Backend
npm install
npm start

Server runs on:

http://localhost:4001


 Run Frontend

cd Frontend
npm install
npm run dev

Frontend runs on:

http://localhost:5173


 🔑 Environment Variables

Create a `.env` file inside **Backend**

PORT=4001
MONGO_URI=your_mongodb_connection_string
